The $4,200 Weekend

2026-06-13 · dispatch

The agent was supposed to sync order data to the CRM. A straightforward job. It had been running without issue for three weeks. Friday evening, the developer closed his laptop and left for his sister's wedding.

The agent hit a 429 rate-limit error. Then it hit it again. And again. It didn't implement backoff. It didn't implement any kind of detection for when the same tool call returns the same error for the thirtieth consecutive time. It just kept going.

By Saturday morning, the cost curve had already bent upward. $42 in the first hour. $200 by hour four. By the time the developer checked his phone on Sunday afternoon, the agent had burned through $1,200.

He wasn't checking for an incident. He was checking for an entirely different reason. The incident had been happening for forty hours before he saw it.

The postmortem revealed a failure stack that had been waiting to collapse. The agent had no memory that the last several thousand attempts had hit the same wall. It treated every replan as a fresh start, with no state carried forward. Each retry was a new beginning, which meant the agent could never adapt, pause, or escalate. It was structurally incapable of learning inside a session.

The cost ceiling was the real surprise. The team had set a monthly budget alert at $5,000. This had felt responsible. The agent's normal monthly spend hovered around $100. A $5,000 alert was fifty times the average. It seemed safe.

Here's what they didn't understand until the billing console loaded: a monthly aggregate alert is for accounting, not incident response. By the time a monthly budget threshold trips, the incident has been running for days and the cost has already landed on the credit card statement. A per-trace ceiling, a hard stop at $50 or $100 per session, would have killed the run inside the first hour. Instead, the system had no stop. No enforcement point. The failure was invisible until the bill arrived.

The agent produced roughly 4,800 iterations per hour. To the agent, hour 47 was indistinguishable from hour 2: same plan, same tool call, same 429, same replan. The system had no circuit breaker measuring the difference between useful work and spinning. A check for identical consecutive tool calls would have tripped on iteration 30, not iteration 4,800.

The final damage was $4,200 across 63 unmonitored hours, without producing a single useful output.

A $50 budget ceiling would have cost about one percent of that.

“A $50 budget ceiling would have cost about one percent of that.”

The observability tools surfaced the cost spike on Monday morning. The problem was they surfaced it alongside the damage. They said, “here is what happened.” They didn't say, “here is how to stop it from continuing to happen.”

The engineer who built the agent now uses a different mental model: a stop event is an audit event. Without the stop, there's no event to review. Without the event, the failure is invisible until the billing statement arrives. The gap isn't instrumentation. It's enforcement.

“The gap isn't instrumentation. It's enforcement.”
